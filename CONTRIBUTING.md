# Contributing

Thanks for your interest in improving Pax Studio.

## How to Contribute

1. Fork the repository.
2. Create a branch for your change.
3. Keep the project simple: plain HTML and CSS, no build step unless there is a clear need.
4. Test the page locally in a browser.
5. Open a pull request with a short description of the change.

## Good First Contributions

- Improve accessibility and responsive layout details.
- Update project links and copy.
- Refine styles while keeping the page lightweight.
- Improve documentation.

## Maintainer Notes

The maintainer reviews changes for simplicity, readability, and whether they fit the purpose of a small GitHub Pages landing page.
